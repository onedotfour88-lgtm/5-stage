# 케셰브 16단계 검토용 소스

이 브랜치는 약 250KB 검토 한도에 맞춘 코드 검토용 스냅샷입니다. 독립 실행용 프로젝트가 아닙니다.

전체 실행 프로젝트와 1~16단계 기록은 main 및 원본 커밋 5ba02f7c0241588a22a81d0f293ff4e2b51eac37 에 보존합니다. 바탕화면 project5의 main에서 npm --prefix on-client start 로 실행합니다.

학생 구현: on-client/student/extension.mjs. 13~16단계 함수를 모두 원문 그대로 포함합니다. 제공 UI 파일과 입력 계약도 원문 그대로 포함해 입력 전달과 DOM 교체를 검토할 수 있습니다. 서버, 인증 설정, 이전 과제 파일, 이미지, 중복 설명서는 이 검토 스냅샷에서 제외했습니다. 제공 서버를 수정한 것이 아닙니다.

16단계는 renderStatus의 기기·세션·진단 상태 구분, 알림, 수동 재시도 안내, 여섯 진단 필드만 표시·복사와 renderEvents 상세의 비활성 미지원 조치 버튼입니다. 학생 코드의 네트워크 요청이나 자동 재시도는 없습니다.

검증: Node 구문 검사와 모의 DOM 검사 20개 성공. 모의 검사는 실제 계정의 결과나 공식 통과 판정이 아닙니다. 이번 정리는 실행 코드를 바꾸지 않았으며 실제 화면·클립보드와 공식 재판정은 별도 확인이 필요합니다.
