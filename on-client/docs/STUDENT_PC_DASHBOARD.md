# 케셰브 「내 PC 상태」 대시보드 — 실행 안내 한 장

처음 보는 사람도 이 한 장만 보고 실행하고, 화면을 읽고, 막혔을 때 확인할 수 있게 썼습니다. 제공 문서는 고치지 않았습니다. **「실제 측정」**은 이 PC에서 2026-10-27 09:43~09:46(UTC+09:00)에 직접 읽은 값이고, **「예시」**는 설명용 값입니다. 둘은 아래에서 따로 표시합니다.

## 0. 한눈에

- 케셰브 보호 현황 화면 맨 위에 「내 PC 상태」가 붙습니다. 상태 카드 4개(CPU·메모리·디스크 남은 공간·방화벽), 아래에 추이와 기록, 네트워크 구성, Windows 경고·오류 건수, 그리고 따로 SDP 연결 상태가 나옵니다.
- 읽기 전용이고 일반 권한(관리자 아님)으로만 읽습니다. 방화벽·보안 설정은 바꾸지 않습니다. 관리자 권한이 필요한 항목은 「확인 불가」와 이유로 표시합니다.
- Windows 경고·오류 건수는 **침해나 공격 탐지 결과가 아닙니다.**
- 화면 틀은 「관제 대시보드형」(맨 위 상태 카드 4개, 아래 추이와 기록)입니다. 포장 형태는 「기본 포장 뒤 Inno Setup 설치 프로그램」으로 정했지만 **아직 만들 수 없습니다**(9장).

## 1. 준비물

| 항목 | 내용 | 이 PC에서 확인한 값 |
|---|---|---|
| OS | Windows (방화벽·Windows 기록 조회가 Windows 전용) | Windows 11 Pro 10.0.26100 |
| Node.js | 24.19.0 (수업 기준) | v24.19.0 |
| PowerShell | Windows PowerShell | 5.1 |
| 권한 | 일반 사용자 권한이면 됩니다. 관리자로 실행하지 않습니다. | 관리자 아님 확인 |
| 설치할 패키지 | 없음 (`npm install` 불필요) | — |

## 2. 실행 (3단계)

1. 파일 탐색기에서 `on-client` 폴더를 열고 주소 표시줄에 `powershell`을 입력해 Enter를 누릅니다.
2. 아래 명령을 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```

3. 브라우저에서 `http://127.0.0.1:5189/`를 엽니다. 「보호 현황」 맨 위에 「내 PC 상태」가 보이면 정상입니다.

- **정상 시작 신호**: 실행 창에 앱이 켜졌다는 안내와 서버가 응답했다는 안내가 나옵니다. 5189를 다른 프로그램이 쓰고 있으면 `... -Port 5190`을 붙이고 주소도 `:5190`으로 엽니다.
- **종료**: 실행한 PowerShell 창에서 `Ctrl+C`. 창 없이 켰다면(`-Background`) 안내된 프로세스 번호의 node를 작업 관리자에서 종료합니다.
- **재실행**: 같은 폴더에서 2번 명령을 다시 실행합니다. 화면의 추이 기록은 지워집니다.

## 4. 키보드만으로 쓰기

`Tab`으로 「다시 조회」에 초점을 옮기고 `Enter` 또는 `Space`를 누릅니다. 조회 중에도 초점이 버튼에 남아 있어 이어서 누를 수 있습니다(조회 중 중복 요청은 무시). 결과 알림은 화면 낭독기가 읽는 상태 영역(`role=status`)에 나옵니다. 이 PC에서 `Enter`와 `Space` 둘 다 실제로 눌러 재조회와 초점 유지를 확인했습니다.

## 9. 포장(Inno Setup 설치 프로그램) 상태

- 정한 방식: 기본 포장 뒤 Inno Setup 설치 프로그램(`setup.exe`, 사용자 단위 설치).
- 이 시작 틀(0.2.11)의 `package.json`에는 `package-app` 명령이 **없고**, Inno Setup(`ISCC.exe`)도 이 PC에 **설치되어 있지 않습니다.** 과제 안내대로 포장은 건너뛰고 기능·화면 작업을 계속했습니다.
- 새 포장 스크립트를 만들거나 승인 파일을 만들어 우회하지 않았습니다. `package-app`과 승인 실행 환경은 담당자(또는 새 시작 틀) 준비가 필요한 항목입니다. 포장은 내 PC에서 써 보는 연습이며 마무리 제출은 저장소 주소와 커밋 번호로 합니다.

## 10. 같은 결과를 다시 만드는 방법

`on-client` 폴더에서 아래를 순서대로 실행합니다.

```powershell
node --check student/extension.mjs
node test/pc-dashboard.mjs
node test/pc-status-collector.mjs
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -Port 5197
```

| 확인 순서 | 정상 결과 |
|---|---|
| 1. 처음 두 명령 | 문법 오류 없음, `pc-dashboard.mjs` 12개 통과(합성 입력) |
| 2. `pc-status-collector.mjs` | 5개 통과, `actualMeasurement: true`(이 PC를 실제로 한 번 측정함) |
| 3. 서버 실행 후 `http://127.0.0.1:5197/` | 「보호 현황」 맨 위에 카드 4개, 값마다 잰 시각 |
| 4. 「다시 조회」 | 잰 시각이 바뀌고 추이 행이 늘어남 |
